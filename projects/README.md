# Projects

This directory will contain individual project folders for Summer of Science 2026 participants.

Each project should be added as a subdirectory following the naming convention:

```
projects/<your-name>-<project-topic>/
```

For example: `projects/alice-quantum-computing/`

Inside your project folder, include:
- `README.md` – Project title, description, and your name
- `resources.md` – Reading list and useful links
- Any notes, code, or other materials relevant to your project
